"04 / Engineering Philosophy"

class Engineer {
public:
    void build() {
        simplicity();
        reliability();
        performance();
        maintainability();
    }

private:
    void simplicity();
    void reliability();
    void performance();
    void maintainability();
};

I care about:

- Clean architecture — complexity should live where it belongs.
- Performance — measure first, optimize second.
- Reliability — software should behave predictably under pressure.
- Maintainability — today's clever solution is tomorrow's technical debt.
- Automation — if it can be automated, it probably should be.
- Learning — technologies change; engineering fundamentals don't.
